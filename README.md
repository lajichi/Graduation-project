# 基于深度强化学习的双边谈判让步策略研究（本科毕业设计）

本项目的任务：让卖方学会"怎么让步"。

- **基线**：手写的 Tit-for-Tat 卖方策略（买家加价多，我就多降；买家死扛，我先忍几轮再顶回去）。
- **方法**：用 DQN（深度 Q 网络，MLP 版本）训练一个卖方，让它自己从模拟谈判里学出降价节奏。
- **对比**：在完全相同的随机场景上，逐局比较 DQN 卖方和 Tit-for-Tat 卖方的成交率、双方收益和议价效率。

## 三、怎么跑

```bash
python simulate.py            # 1. 基线实验：手写买方 vs Tit-for-Tat
python train_dqn.py           # 2. 训练 DQN 卖方（约 1.5 分钟，CPU 即可）
python evaluate_dqn.py        # 3. 评估：DQN vs Tit-for-Tat，带显著性检验
python plot_results.py        # 4. 生成论文插图（存到 figures/）
python sweep.py               # 5.（可选）Tit-for-Tat 响应系数敏感性分析
python play.py --seller dqn   # 6.（可选）自己上去砍价
```

常用参数：

```bash
python train_dqn.py --episodes 5000 --seed 0 --step-cost 0.1 --out models/my_model.pt
python evaluate_dqn.py --model models/my_model.pt --games 500
```

## 四、实验设置

| 项目 | 取值 |
| --- | --- |
| 买方预算上限 `BUYER_TOP` | 100 |
| 买方首次出价 `START_OFFER` | 40 |
| 买方保留价（最多愿意出多少） | 50~100 均匀随机 |
| 卖方底价（成本） | 40~90 均匀随机 |
| 卖方起始报价 | 60~100 均匀随机，且不低于底价 |
| 单局最大轮数 | 10 |
| 每局样本量 | 500（每种买方策略 × 每个卖方） |
| Tit-for-Tat 响应系数 | 0.7 |

**可复现性**：每一局都先 `random.seed(seed)` 再抽场景，所以 500 局用到的场景是固定的；
两个卖方（DQN / Tit-for-Tat）面对的是**同一批场景和同一个保留价**，因此可以做配对检验。
训练脚本也固定了随机种子（`--seed`，默认 0）。

## 五、指标定义

设成交价为 `P`，卖方底价 `B`，买方保留价 `R`：

| 指标 | 定义 |
| --- | --- |
| 成交率 | 成交局数 / 总局数 |
| 可成交场景 | `R >= B`：这个场景理论上存在双方都能接受的区间 |
| 可成交场景成交率 | 在有共同利益区间的场景里成功成交的比例（衡量"该成交的有没有成交"） |
| 卖方收益 | `P - B`（未成交记 0） |
| 买方收益 | `R - P`（未成交记 0） |
| 联合收益 | 双方收益之和，衡量社会总福利 |
| 卖方分成 | `(P - B) / (R - B)`，即共同增益里卖方拿走多少，1 表示卖方通吃 |
| 95% 置信区间 | 比例用 Wilson 区间，均值用正态近似 |
| 显著性检验 | 成交率用 McNemar 配对检验，收益用配对 t 检验 |

## 六、主要结果

### 6.1 基线：手写买方 vs Tit-for-Tat（`python simulate.py`）

| 买方策略 | 成交率 | 可成交场景成交率 | 均价 | 均轮数 | 卖方收益 | 僵局局数 |
| --- | --- | --- | --- | --- | --- | --- |
| 让步型 Conceder | 64.8% | 92.0% | 70.51 | 5.4 | 6.70 | 176 |
| 时间依赖型 TimeDependent | 64.2% | 91.2% | 71.38 | 9.0 | 7.14 | 179 |
| 固定报价型 Grandet | 55.4% | 78.7% | 84.29 | 2.4 | 13.17 | 223 |
| 反应型 Reactive | 2.6% | 3.7% | 48.17 | 9.2 | 0.10 | 487 |
| 随机加价型 Random | 60.8% | 86.4% | 69.76 | 6.0 | 6.60 | 196 |

> 反应型买方几乎谈不成：它只在卖方单轮降幅 ≥ 2 时才加价，而 Tit-for-Tat 遇到"买方不加价"
> 时的应对是每轮只降 0.5~1 块钱，甚至开始反向涨价，两边一起把局面拖死。
> 这正好说明**手写规则策略在对手不配合时非常脆弱**，也是引入学习型策略的动机之一。

### 6.2 主实验：DQN 卖方 vs Tit-for-Tat 卖方（`python evaluate_dqn.py`，各 500 局）

| 买方策略 | DQN 成交率 [95%CI] | TFT 成交率 [95%CI] | DQN 可成交成交率 | TFT 可成交成交率 | DQN 卖方收益 | TFT 卖方收益 | 显著性 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 让步型 | 70.4% [66.3,74.2] | 64.8% [60.5,68.9] | 100.0% | 92.0% | 10.77 | 6.70 | *** |
| 时间依赖型 | 65.4% [61.1,69.4] | 64.2% [59.9,68.3] | 92.9% | 91.2% | 7.54 | 7.14 | n.s. |
| 固定报价型 | 70.4% [66.3,74.2] | 55.4% [51.0,59.7] | 100.0% | 78.7% | 15.18 | 13.17 | *** |
| 反应型 | 35.2% [31.1,39.5] | 2.6% [1.5,4.4] | 50.0% | 3.7% | 2.84 | 0.10 | *** |
| 随机加价型 | 66.8% [62.6,70.8] | 60.8% [56.5,65.0] | 94.9% | 86.4% | 8.90 | 6.60 | *** |
| **以牙还牙型（训练时没见过）** | 42.2% [37.9,46.6] | 9.2% [7.0,12.1] | 59.9% | 13.1% | 3.66 | 0.66 | *** |

`***` 表示 p < 0.001，`n.s.` 表示不显著。收益比较用配对 t 检验，成交率比较用 McNemar 检验。

三条结论：

1. **成交能力更强**：五类训练对手里有四类成交率显著更高，固定报价买方（一口价）场景提升最大（+15.0 个百分点）。
2. **对手越硬，优势越大**：面对反应型买方，Tit-for-Tat 几乎完全谈崩（成交率 2.6%），DQN 能救回 35.2%。
3. **没有明显过拟合**：对训练时完全没见过的"以牙还牙型"买方，DQN 的成交率 42.2% 仍是 Tit-for-Tat（9.2%）的 4 倍多。

### 6.3 消融实验：每轮时间成本 `step_cost` 的作用

奖励函数里原本只有"成交收益 + 等待买方加价的 shaping 奖励"，没有为"拖轮次"付代价。
给每多磨一轮加一点点成本（`--step-cost 0.1`）后：

| 买方策略 | 可成交场景成交率（无成本 → 有成本） | 卖方收益（无成本 → 有成本） |
| --- | --- | --- |
| 让步型 | 100.0% → 100.0% | 10.17 → 10.77 |
| 时间依赖型 | 96.9% → 92.9% | 10.42 → 7.54 |
| 固定报价型 | 100.0% → 100.0% | 15.18 → 15.18 |
| 反应型 | 48.0% → 50.0% | 2.65 → 2.84 |
| 随机加价型 | 94.9% → 94.9% | 8.71 → 8.90 |
| 以牙还牙型（未见） | 53.1% → 59.9% | 2.74 → 3.66 |

结论：时间成本**提高了对未见对手的泛化能力**（+6.8 个百分点）和最难对手的成交率，
代价是在"时间依赖型买方"这种慢热对手上少赚了一点——典型的**鲁棒性与收益之间的权衡**。
两个模型都保存在 `models/` 里，可以复现这张表。

## 七、方法实现要点（写论文可以直接用）

**状态（6 维）**：买方本轮报价 / 上一轮报价 / 卖方当前报价 / 卖方底价 / 剩余轮次比例 / 买方重复出价次数。

**动作（5 个离散档位）**：本轮降价 0、2、5、10、15。

**奖励**：

- 成交（买方出价 ≥ 卖方新报价）：`成交价 - 卖方底价`；
- 中间轮：`0.3 × 买方本轮加价 - step_cost`，鼓励"等买家先加价"，但拖轮次要付代价；
- 谈崩（跑满 10 轮）：`-1.0`。

**DQN 四件套**：两层 64 隐单元 MLP 的 Q 网络；经验回放池（容量 10000，batch 32）；
每 100 步同步一次的 target 网络；epsilon 从 1.0 指数衰减到 0.05（衰减尺度 500 步）。
梯度按 [-1, 1] 裁剪防爆炸。

**训练**：5000 局，每局随机抽场景并从 5 种买方里随机选一个对手；CPU 上约 90 秒。

## 八、局限与可以继续做的方向

1. **状态里没有对手模型**：网络只能看到价格和轮次，看不到"对面是哪种人"。
   可以加对手类型的 one-hot，或者把估计出的对手让步率放进状态。
2. **评估的配对是"场景级"的**：两个卖方面对同样的场景和保留价，但对手内部的随机数流不完全同步。
3. **没有训练收敛性的严格验证**：目前只看了 5000 局内滑动曲线的波动，
   可以多跑几个随机种子，画"均值 ± 标准差"的误差带。
4. **动作空间是固定档位**：可以改成连续动作（DDPG / SAC），让降价幅度更细腻。
5. **只有单边学习**：买方是固定的脚本。双边都学习（MARL）会更接近真实谈判。
